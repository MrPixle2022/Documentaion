# Setup

having installed the rustup we can create a new project using:

```bash
# update rust
$ rustup update
# uninstall rust
rustup self uninstall

#open local docs
rustub doc

# create a new project
cargo new <project-name>

# compile and run the app
rustc <path_to_file>
<path_to_build>

# for example:
rustc ./src/main.rs
./main
```
